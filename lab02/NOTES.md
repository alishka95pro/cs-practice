Рабочая папка - это файлы проекта, с которыми я работаю на компьютере.



Индекс - это область, куда Git помещает изменения, подготовленные для следующего коммита.



Коммит - это сохранённая версия изменений в истории Git.



Git - это система контроля версий, которая хранит историю изменений проекта на компьютере.



GitHub - это онлайн-сервис, который позволяет хранить Git-репозитории и работать с ними удалённо.
